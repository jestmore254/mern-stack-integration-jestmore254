
# MERN Stack Integration Project

This project demonstrates a full MERN (MongoDB, Express.js, React.js, Node.js) stack setup, showcasing API communication, CRUD operations, and state management using React.

## Folder Structure

- `client/` — Frontend built with React and Tailwind CSS
- `server/` — Backend powered by Express.js and MongoDB
- `README.md` — Project documentation

## Setup Instructions

1. **Backend Setup**
   ```bash
   cd server
   npm install
   npm start
   ```

2. **Frontend Setup**
   ```bash
   cd client
   npm install
   npm run dev
   ```

3. **Environment Variables**
   Create a `.env` file in `server/` containing:
   ```env
   MONGO_URI=your_mongodb_connection_string
   PORT=5000
   ```

4. **Run the App**
   Access the app at `http://localhost:5173/`
